> A modern, lightweight productivity extension for Google Chrome that closes active or temporary tabs automatically using precise countdown timers.

---

## 🌟 Overview

**Tab Expiry Auto-Closer** (v2.1) helps users declutter their browser workspaces and reduce RAM overhead. Whether you are researching, opening temporary links, or working against tight deadlines, set custom lifespan timers for individual tabs to close them automatically when time expires.

---

## Key Features

- ⏱️ **Live Countdown Timer:** Displays real-time `MM:SS` countdown updates inside the popup interface.
- ⚡ **One-Click Quick Presets:** Instantly initiate timers for standard durations: `1m`, `5m`, `15m`, `30m`, `1h`, or `2h`.
- 🎛️ **Custom Minute Duration:** Specify custom expiration intervals ranging from 1 to 1,440 minutes (24 hours).
- 🔔 **Audio Feedback:** Synthesizes soft user interaction sound cues using native Web Audio API.
- 🛑 **Instant Cancellation:** Abort scheduled closures anytime with a single click.
- 🎨 **Modern Dark UI:** Clean interface styled with custom CSS variables and modern typography.
- 🔒 **Zero Data Tracking:** Operates 100% locally with zero analytics, external requests, or data storage.

## Installation Guide

Since this extension is not yet on the Chrome Web Store, you can install it manually in **Developer Mode**:

1. Click the green **Code** button at the top right of this repository page and select **Download ZIP**.
2. Extract the downloaded `.zip` archive on your computer.
3. Open Google Chrome and navigate to:
   ```text
   chrome://extensions/
   ```
